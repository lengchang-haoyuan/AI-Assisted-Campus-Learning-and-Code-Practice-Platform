## 推荐阅读顺序

快速了解当前工程，可先打开 [ScholarHub 知识地图](知识网络/00-ScholarHub知识地图.md)，再沿链接进入具体模块与交付证据。

1. 阅读 [项目说明](AI辅助校园学习与代码实践平台_项目说明文档.md)。
2. 阅读 [使用顺序](开发规划/使用顺序.md) 和 [P00-P15 开发规划](开发规划/)。
3. 按需查看 [AI 提示词](AI提示词/) 和对应的 [阶段报告](阶段报告/)。
4. 联调或答辩时使用 [P15 演示与答辩指南](答辩材料/P15演示与答辩指南.md)。
5. 继续校园试点路线时，从 [P16 试点需求与数据设计](AI提示词/P16_试点需求与数据设计.md) 开始；P17 校园身份和 P18 班级任务已经实现并有对应验收报告，P19-P24 待执行，设计、实施与真实试点批准分开记录。

## 入口文件说明

根目录 `README.md` 保留为 GitHub 项目入口；根目录 `PRODUCT.md` 保留为 Impeccable 使用的产品设计清单。两者都不是运行时依赖，保留原位置是为了不破坏项目入口和设计工具约定。

## Obsidian 入口

将本目录 `开发相关文档` 作为独立仓库打开，原有报告、规划和证据无需复制。知识网络入口为 `知识网络/00-ScholarHub知识地图.md`；打开 Obsidian 内置关系图谱并按 `path:知识网络` 筛选，可只观察当前项目的核心知识节点。

知识笔记提交到 Git；Obsidian 自动生成的 `.obsidian/` 窗口状态和本地设置不提交。旧 `docs/` 只有空目录，已移除；后续报告继续放在本目录的既定分类下。
