## 使用建议

1. 先在项目详情阅读目标、边界和交付要求。
2. 自己完成源码并记录测试结果；不要把“项目已录入”当成“练习已完成”。
3. Vue 项目使用虚构样本，不录入真实学生、财务或账号数据。
4. 需要教师发布时，另行选择项目模板并经过校园社区/教学权限流程。
