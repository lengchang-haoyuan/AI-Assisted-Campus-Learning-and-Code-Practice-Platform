# 个人工作台

工作台聚合当前用户的任务、近期项目、学习进度和记录。它展示 [[07-项目管理]] 与 [[10-课程计划任务与记录]] 的同一批数据，不是独立的演示统计。

## 页面和数据

| 页面 | 用途 |
| --- | --- |
| `/workspace/dashboard` | 今日任务、近期项目和学习概况 |
| `/workspace/tasks` | 创建和完成个人任务，关联自己的项目 |
| `/workspace/projects`、`/workspace/projects/:id` | 项目进度和关联信息 |
| `/workspace/records` | 保存、查看学习记录 |

接口位于 `/api/v1/workspace/*`。Dashboard 使用后端聚合，不由前端写死数字；个人资源均按当前用户隔离。

## 一条真实操作线

先创建自己的 Project → 新建关联任务 → 完成任务 → 保存真实学习内容和分钟数 → 刷新 Dashboard、项目进度和记录页。

任务完成和学习记录保存是不同事实：完成状态不自动证明学习了某段时间，不能为填充页面捏造学习记录。记录完整编辑与计划关联在学习系统中完成。

## 进度口径

只计算项目所有者的关联任务完成率；没有任务时使用项目自身 `progress`。工作台、统计和新报告的口径在 P15 做过统一，见 [[16-统计与AI学习报告]]。
