# ScholarHub 知识地图

**AI 辅助校园学习与代码实践平台**：围绕项目，将校园代码社区、个人学习、可视化 Workflow、AI 辅助分析与数据报告连接起来。

当前代码已经完成 P00-P18，其中 P16 是校园试点设计，P17-P18 实现校园身份、教学班和教学任务；这仍是毕业设计版本，不代表已经投入学校运营。功能实现、前端可操作性、案例内容和真实用户使用是四个不同维度，见 [[01-产品定位与当前边界]]。

## 核心关系

用户拥有项目；项目连接社区发布、任务、学习记录和 Workflow。Workflow 的节点依赖 ProjectContext，经 Agent 和 Provider 获取结构化结果；真实学习及使用记录汇总为统计与个人学习报告。校园资格独立于普通账号，教学班、班级成员和教学任务也不复用个人 Course 或 DailyTask。
