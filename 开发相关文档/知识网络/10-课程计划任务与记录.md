# 课程、计划、任务与记录

`Course → LearningPlan → DailyTask → LearningRecord` 构成个人学习链，计划和任务还可关联 [[07-项目管理]]。Course 目前是个人课程，不是教师授课班级。

## 最短操作流程

1. `/learning` 创建课程，随后创建有日期范围的学习计划并引用课程。
2. `/learning/tasks` 添加任务，关联计划或自己的项目。
3. 完成任务，确认返回的状态和计划进度。
4. `/learning/records` 保存内容、时长、日期和来源，刷新读取。
5. 在 [[09-个人工作台]] 与 [[16-统计与AI学习报告]] 中观察同一数据的聚合。

## 状态规则

计划从 `draft` 到 `active`，再到 `completed/cancelled`；完成和取消是终态。计划仍有未完成任务时不能直接宣布完成。

任务的 `pending` 与 `in_progress` 可以按服务规则切换，最终进入 `completed/cancelled`；终态不能随意重新打开。相关失败应回报冲突，不伪造成功。

记录类型为 `study/project/workflow/ai/course/task`。记录是学习活动的结构化存档，`workflow` 和 `ai` 类型标签本身不证明真的执行过模型调用。

## API 和权限

`/api/v1/courses`、`/learning/plans`、`/learning/tasks`、`/learning/records` 提供相应读写接口；任务完成使用专门完成入口。分页、标题、分钟数、日期与状态由 Schema/Service 双重边界处理。

关联的课程、计划、任务、项目都必须属于当前用户。删除关联对象时保留哪些学习数据，由 [[05-数据库实体关系]] 的可空外键和服务规则共同决定。
