# 项目目录与文档导航

## 当前目录职责

| 路径（相对项目根目录） | 作用与整理规则 |
| --- | --- |
| `frontend/src/` | Vue 页面、组件、Store、API、类型和路由；不为整理报告而移动 |
| `frontend/scripts/` | 登录和会话的浏览器验证脚本 |
| `frontend/public/`、`frontend/src/assets/` | 前端静态资源；是否被引用需要逐项检查，不能按名称删除 |
| `backend/app/` | FastAPI 分层业务与 AI/Context/Workflow 实现 |
| `backend/schema.sql`、`backend/migrations/` | 建库及增量迁移，参与部署，保留原位置 |
| `backend/tests/`、`backend/scripts/` | 自动化测试、数据库和跨模块验收脚本 |
| `开发相关文档/` | 说明、规划、提示词、日志、报告、证据、答辩材料和本知识网络 |
| `README.md`、`backend/README.md` | 项目和后端启动入口 |
| `PRODUCT.md` | Impeccable 产品设计约定，保留入口名称 |
| `.git/`、`.pnpm-store/`、`.impeccable/`、`assets/` | Git、依赖缓存和设计相关文件，本轮不删除 |

旧 `docs/ai-worklogs/` 树仅余空文件夹，本轮检查后删除了 `docs` 及其 4 个空子目录。后续文档不再写回旧路径。

## 文档分工

- [[README|文档分类入口]]：原资料统一索引。
- [[AI提示词/README|AI 提示词]]：给后续开发使用，不是完成证明。
- [[开发规划/使用顺序|规划执行顺序]]：阶段关系与当前基线。
- [[开发日志/开发操作日志|开发操作日志]]：恢复工作时先查看最近记录。
- [[18-测试证据与答辩]]：从测试脚本追到已有报告和截图。

Obsidian 仓库根目录是 `开发相关文档`，不是其他项目已有的知识库。笔记采用双向链接，白板引用同一份笔记，不复制历史报告。`.obsidian/` 仅保存本机界面状态，不纳入 Git。

源码定位按项目根目录理解；该目录不属于 Obsidian 文档仓库，代码仍在原工程中编辑。
