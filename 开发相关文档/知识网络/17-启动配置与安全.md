# 启动、配置与安全

既有本机环境启动顺序：MySQL → FastAPI → Vue。完整首次安装流程位于项目根目录 `README.md` 和 `backend/README.md`，不要覆盖已有 `.env`。

## 已安装环境的 Windows 启动命令

在项目根目录打开 PowerShell 后：

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

另一个 PowerShell 窗口进入项目根目录：

```powershell
cd frontend
pnpm dev
```

默认前端 [本地页面](http://127.0.0.1:5173)、后端 [Swagger](http://127.0.0.1:8000/docs)、[Health](http://127.0.0.1:8000/api/v1/health)。这些是启动后的访问地址，不是本轮已检查服务在线的结论。端口占用时先确认进程，不能停止未知服务。

## 环境变量

- 前端 `VITE_API_BASE_URL`：Axios 基地址，包含 `/api/v1`。
- 后端 `DATABASE_URL`、`JWT_SECRET`、`JWT_ALGORITHM`、`JWT_EXPIRE_MINUTES`：数据库与认证。
- AI Provider、模型、Key、超时与预算：只在后端本地配置。
- CORS 使用配置中的明确来源；前端端口变化需对应核对。

只提交 `.env.example` 占位说明。密码、API Key、JWT Secret、认证头和原始私人输入不写知识库、日志或 Git。

## 数据和部署边界

空库按 `schema.sql` 初始化；已有库先备份、审查并按增量迁移处理，不重跑建库当作升级。P14、P17、P18 迁移依次位于 `backend/migrations/20260902_p14_statistics.sql`、`20260905_p17_campus_identity.sql`、`20260907_p18_classrooms_assignments.sql`，MySQL DDL 不能被假定整份原子回滚。

校园迁移不会自动创建管理员、教师、学生、班级或任务。首管理员只能在负责人核验现有账号后使用 `python -m app.cli.init_campus_admin` 初始化；仓库不包含默认密码或真实邀请凭证。

当前单 worker；滑块内存状态和部分执行限制不能当作多进程共享能力。Redis 未接入，也不因为没有 Redis 宣称数据丢失；业务数据保存到 MySQL。

常见排查：health 正常但登录失败 → 核对 MySQL/JWT/滑块；请求 401 → 重新登录，校园角色变化也会使旧会话失效；AI 503 → 核对后端 Provider 配置；Context 或 revision 409 → 刷新后按新版本重试。
