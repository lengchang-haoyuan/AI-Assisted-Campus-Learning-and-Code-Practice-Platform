# 项目管理

Project 是平台的中心资源：归属于当前用户，连接 [[08-校园代码社区]]、[[10-课程计划任务与记录]]、[[11-Workflow可视化编辑器]] 和 [[12-ProjectContext上下文]]。

## 创建项目究竟保存什么

填写名称、说明、难度、语言、框架、前端/后端/数据库、需求列表、输出要求和状态。后端保存资料，刷新后仍从 MySQL 查询；这一步不会下载源码、启动项目或自动完成学习任务。

项目状态为 `not_started/in_progress/completed/published/archived`；发布可见性另有 `is_published` 和发布时间，不能只改状态文本就认为已进入社区。

## 操作路径

1. 登录后进入 `/projects`，创建自己的项目。
2. 打开 `/projects/:id` 查看和编辑；创建者由服务端认证结果确定。
3. 需要分享时使用发布动作进入社区；需要实践时建立关联任务和 Workflow。
4. 删除需要确认，且受数据库外键与所有权规则限制。

## API 与约束

`GET/POST /api/v1/projects`；`GET/PUT/DELETE /api/v1/projects/{id}`。列表按创建时间及 ID 降序分页，页大小 1-100；没有数据时返回空列表及总数 0。

名称最长 120、说明最长 5000 字符；难度和状态使用枚举。更新不接受 `owner_id`，服务端禁止修改或删除其他用户项目。

当前 ORM 存在 `repository_url` 字段，但创建/更新和社区响应 Schema 尚未开放它。后续补齐开源案例时不能假定输入仓库地址就会自动导入，见 [[20-项目内容补齐]]。
