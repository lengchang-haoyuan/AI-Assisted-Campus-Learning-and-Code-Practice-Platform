# 前端架构与页面

Vue 3 + TypeScript + Vite；Vue Router 管导航，Pinia 管领域状态，Axios 访问后端，Element Plus 提供基础组件，Vue Flow 和 ECharts 分别承担流程图与统计图。

依赖以 `frontend/package.json` 和 `frontend/pnpm-lock.yaml` 为准，沿用 pnpm，不因为原规划的版本描述而降级当前锁定依赖。

## 边界

`views/components → stores → api → Axios → FastAPI`；具体页面也会使用 API 封装，但不在组件里散落后端地址。`types/` 定义契约，`domain/` 处理画布及表单领域转换。

`src/api/client.ts` 统一读取 `VITE_API_BASE_URL`、注入 Bearer Token、处理 401。普通请求默认 5 秒，报告生成使用独立长超时。恢复会话及退出逻辑见 [[06-账号认证与权限]]。

`LiquidTabs`、`NumberRoller`、`ProjectFlipCard` 与 `SliderCaptcha` 承担现有高级交互；视觉基调见 [[界面设计/界面设计说明|设计说明]]。动画不替代错误、加载和空数据反馈。

## 当前缺口

Workflow 编辑器已经接入运行、失败续跑、全部重跑、历史分页和结构化结果展示；`WorkflowResultPanel.vue` 仍负责图检查，实际 AI 结果由 `WorkflowExecutionPanel.vue` 展示。独立 Context/Agent 页面和 P19 成果提交页面尚未实现。
