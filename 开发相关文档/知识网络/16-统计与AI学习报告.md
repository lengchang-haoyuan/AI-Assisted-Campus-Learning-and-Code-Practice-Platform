# 统计与 AI 学习报告

`/analytics` 使用 ECharts 展示真实数据库聚合，并提供当前用户学习报告的生成与查询。统计和报告是两条不同权限的数据链。

## 统计口径

| API | 内容与范围 |
| --- | --- |
| `/api/v1/statistics/today` | 全平台匿名聚合；今日访问、完成任务人数、项目和互动等 |
| `/statistics/trend` | 有界 7/30 日趋势 |
| `/statistics/projects` | 项目状态、完成趋势和进度 |
| `/statistics/tech-stacks` | 有界技术栈分布 |

“今日访问人数”按 `project_views.user_id` 去重，不是所有网页访客；完成任务人数按完成时间去重；互动由浏览、未删除评论、点赞和收藏组成。零补齐表示没有事件，不是生成活动。

数据库统一 UTC；前端传 `timezone_offset_minutes` 定义日界线。项目完成时间独立保存，不把迁移前已完成项目虚构成某天完成。

## 个人报告

`POST/GET /api/v1/learning-reports` 和 `GET /learning-reports/{id}`，按用户隔离、周期最多 90 天。

Repository 聚合 [[10-课程计划任务与记录]]、[[07-项目管理]]、Workflow 与 AI 使用情况 → LearningReportAgent → Schema 校验 → `AIRequest/AIResult/learning_reports`。

输出包含 `summary/achievement/problems/suggestions/structured_data`；ORM 使用 `achievements` 保存成就列表，由服务/响应映射衔接，不能机械混用字段名。失败持久化为 failed 或给出明确错误，同周期未过期重复生成返回冲突。

报告不把学习记录正文或完整敏感 Prompt 交给模型；项目进度按当前用户的关联任务完成率计算，无任务时回退 `projects.progress`。报告是生成时快照，不随日后数据变化自动重写。

源码：`backend/app/repositories/statistics.py`、`project_progress.py`、`app/services/learning_report.py`、`app/agents/learning_report.py`；`frontend/src/api/analytics.ts`、`src/views/AnalyticsView.vue`。
