# AI 辅助校园学习与代码实践平台——项目说明文档

## 1. 项目定位

本项目是一套面向高校学生的 **AI 辅助学习与代码实践平台**。

项目围绕两个核心模块展开：

1. **校园代码社区**：提供从基础编程习题到课堂项目、综合项目的学习与实践环境，同时支持学生发布自己的项目成果，与其他用户进行简单交流。
2. **个人工作台**：帮助学生管理每日学习任务、课程学习计划、项目开发过程和学习成果，并通过 AI 生成学习计划、项目规划和阶段性学习报告。

项目的核心理念不是让 AI 直接替学生完成代码，而是让 AI 成为学生的“学习与开发助手”：帮助分析需求、拆解任务、生成规范 Prompt、设计开发工作流、制定学习计划和总结学习成果。

本项目定位为毕业设计，因此应重点保证 **功能完整、逻辑清晰、界面现代、技术架构合理、AI 能力具有实际应用价值**，不追求做成大型商业社区。

## 2. 项目整体结构

网站建议采用一个统一首页作为入口。

### 首页

首页主要负责：

- 项目名称与平台介绍
- 平台核心理念介绍
- 两个核心入口：
  - 进入校园代码社区
  - 进入个人工作台
- 简单的数据统计展示
- 平台近期学习/项目数据概览

首页不需要堆叠过多业务功能，重点是让用户快速理解平台定位，并进入两个核心模块。

### 两大核心模块

```text
                    首页
                     │
          ┌──────────┴──────────┐
          │                     │
     校园代码社区            个人工作台
          │                     │
   学习 / 实践 / 分享      计划 / 学习 / 项目
          │                     │
          └──────────┬──────────┘
                     │
                 AI Agent
                     │
          学习规划 / 项目规划
          Prompt / 工作流
          数据分析 / 学习报告
```

# 3. 核心模块一：校园代码社区

## 3.1 模块定位

校园代码社区不是单纯的“代码上传网站”，而是一个围绕 **学习、实践、项目和成果分享** 建立的校园开发社区。

社区内容主要分为两类：

### A. 平台官方项目

由平台预置的学习内容，例如：

- Python 基础练习
- Java 基础练习
- C/C++ 基础练习
- 数据结构基础题
- 算法基础题
- Vue 前端课堂项目
- Spring Boot 后端项目
- Vue + Spring Boot 综合项目
- Python + FastAPI 项目
- 其他适合高校课程实践的项目

难度可以从简单到复杂逐步增加。

例如：

```text
基础练习
    ↓
简单编程题
    ↓
数据结构 / 算法
    ↓
前端课堂项目
    ↓
后端课堂项目
    ↓
前后端综合项目
    ↓
综合实践项目
```

## 3.2 项目详情页

用户选择一个项目后，需要看到完整的项目说明，包括：

- 项目名称
- 项目简介
- 学习目标
- 难度
- 推荐技术栈
- 所需基础
- 项目需求
- 项目任务拆解
- 建议开发步骤
- 推荐工作流
- AI 辅助开发建议

重点不是直接给用户完整代码，而是帮助用户理解：

> “这个项目应该怎么做。”

# 4. 可视化 AI 工作流

这是校园代码社区中最重要、最具有特色的功能之一。

## 4.1 工作流是什么

这里的“工作流”不是普通的静态流程图，而是一个 **可以拖动、编辑、连接和修改的可视化节点系统**。

例如：

```text
需求分析
   ↓
技术栈确定
   ↓
项目结构设计
   ↓
生成 AI Prompt
   ↓
AI 辅助开发
   ↓
代码检查
   ↓
项目测试
   ↓
项目总结
```

每一个步骤都是一个可以拖动的节点。

用户可以：

- 拖动节点
- 修改节点内容
- 添加节点
- 删除节点
- 修改节点之间的连接
- 查看节点输入与输出
- 调整节点执行顺序

毕业设计阶段不需要把它做成复杂的专业工作流引擎，重点实现 **可视化、可编辑、节点之间存在数据关联** 即可。

---

## 4.2 工作流的动态联动

工作流最重要的技术特点是：

**节点之间不能完全独立。**

例如：

```text
技术选择
Python
   ↓
Prompt
请使用 Python + FastAPI ...
   ↓
项目实现
生成 Python 项目结构
```

如果用户把中间节点的技术栈从：

```text
Python
```

修改成：

```text
Java
```

那么后面的节点应该根据这个变化进行相应调整：

```text
Java + Spring Boot
```

对应的 Prompt、项目结构、开发建议等也应该发生变化。

因此工作流节点之间需要建立一定的数据依赖关系。

可以将项目参数作为统一上下文：

```text
ProjectContext
├── project_name
├── language
├── framework
├── frontend
├── backend
├── database
├── difficulty
├── requirements
└── output_requirement
```

节点读取和修改这个上下文，而不是每个节点保存完全独立的信息。

# 5. AI Agent 的定位

AI Agent 是整个系统的重要能力，但不应该设计成“自动写代码机器人”。

它主要承担以下工作：

### ① 项目分析

分析用户选择的项目：

- 项目需求
- 技术难点
- 开发步骤
- 所需知识
- 推荐技术栈

### ② Prompt 生成

根据项目需求生成规范的 AI Prompt。

Prompt 应该尽可能明确：

- 使用什么语言
- 使用什么框架
- 当前环境
- 项目目录
- 输入输出要求
- 编码规范
- 数据库要求
- API 要求
- 前后端关系
- 最终目标

例如：

```text
请使用 Python 3.x + FastAPI 完成后端服务。

要求：
1. 使用 RESTful API；
2. 使用 MySQL；
3. 使用 SQLAlchemy；
4. 项目采用分层结构；
5. 提供用户模块；
6. 提供项目管理模块；
7. 返回统一 JSON 格式；
8. 给出完整项目目录结构；
9. 说明每个核心文件的作用；
10. 不要省略关键实现步骤。
```

平台本身不直接替用户完成整个项目，而是帮助用户得到更高质量的 AI 开发指令。

### ③ 项目开发指导

根据当前工作流节点告诉用户下一步应该做什么。

### ④ 项目检查

可以分析用户提交的项目说明、代码摘要或开发结果，并给出：

- 完成情况
- 可能的问题
- 下一步建议
- 改进方向

# 6. 社区分享功能

除了官方项目之外，社区还应该支持：

> 学生把自己在个人工作台完成的项目发布到社区。

发布内容可以包括：

- 项目名称
- 项目封面
- 项目简介
- 使用技术栈
- 项目截图
- 项目成果
- Git 仓库地址（可选）
- 项目说明
- 作者
- 创建时间

社区用户可以进行简单互动：

- 点赞
- 评论
- 查看
- 标签筛选

不建议毕业设计阶段加入复杂的社交系统、私信、关注、好友关系等功能。

社区的核心闭环应该是：

```text
官方项目
   ↓
学生学习
   ↓
个人工作台开发
   ↓
完成项目
   ↓
发布到社区
   ↓
其他学生浏览 / 点赞 / 评论
```

# 7. 核心模块二：个人工作台

个人工作台是学生自己的学习与开发中心。

它主要解决：

> “我今天学什么、最近在做什么、项目做到哪里、下一步应该做什么？”

---

## 7.1 每日计划

用户可以手动创建每日计划，也可以让 AI 自动生成。

例如用户输入：

```text
明天需要完成 Java 作业，同时学习 Vue，
晚上还要继续完成校园管理系统项目。
```

AI 可以自动生成：

```text
08:30 - 09:30  Java 作业
10:00 - 11:00  Vue 学习
14:00 - 16:00  校园管理系统
19:30 - 20:30  项目问题整理
```

支持：

- 添加任务
- 修改任务
- 删除任务
- 完成任务
- 设置优先级
- 设置时间
- AI 自动规划

---

# 8. 课程表与 AI 学习规划

用户可以录入或上传自己的大学课程表。

系统根据：

- 当前课程
- 每周课程安排
- 用户学习目标
- 当前掌握情况
- 项目需求
- 可用学习时间

由 AI 生成学习计划。

例如：

```text
目标：学习 Java + Spring Boot

第一阶段
Java 基础

第二阶段
面向对象 / 集合 / 异常

第三阶段
Spring Boot

第四阶段
数据库与 MyBatis

第五阶段
Vue + Spring Boot 综合项目
```

同时也可以针对具体项目生成：

> “完成这个项目需要学习哪些知识？”

从而形成：

```text
课程
 ↓
知识学习
 ↓
编程练习
 ↓
项目实践
 ↓
成果总结
```

# 9. 项目管理

个人工作台需要记录用户最近参与的项目。

每个项目至少记录：

- 项目名称
- 项目描述
- 技术栈
- 开始时间
- 最近修改时间
- 完成进度
- 项目状态
- 项目成果
- 项目工作流
- 是否已发布社区

项目状态可以简单划分：

```text
未开始
进行中
已完成
已发布
```

这样可以让个人工作台成为用户自己的项目档案。

---

# 10. 学习成果与 AI 学习报告

这是个人工作台中与“大数据专业”结合比较重要的功能。

系统根据用户的学习数据生成阶段性报告。

例如统计：

- 本周完成任务数量
- 项目完成数量
- 项目提交数量
- 学习时长
- 任务完成率
- 常用技术栈
- 项目类型
- 最近学习趋势

AI 可以进一步将统计结果转化成自然语言报告：

```text
本周你共完成 18 个学习任务，
完成率为 85%。

主要学习方向为 Python 和 Vue。

本周完成 1 个综合项目，
目前项目开发能力主要集中在前端方向。

建议下周增加 Java / Spring Boot 的后端实践。
```

这样既有数据统计，又有 AI 分析。

# 11. 语音输入

个人工作台可以加入基础语音输入能力。

例如用户点击麦克风：

> “帮我安排明天上午学习 Java，下午完成 Vue 项目。”

系统将语音转换为文字，再交给 AI Agent 分析，并自动生成任务。

毕业设计阶段建议只做：

```text
麦克风
 ↓
语音识别
 ↓
文本
 ↓
AI Agent
 ↓
任务 / 计划
```

不需要开发复杂的实时语音助手。

# 12. 平台数据分析

为了体现大数据专业特点，可以增加平台级数据统计。

主要放在首页或社区首页。

例如：

### 今日数据

- 今日访问人数
- 今日完成题目人数
- 今日完成项目数量
- 今日提交项目数量
- 今日社区互动数量

### 趋势数据

统计最近 7 天或 30 天：

```text
访问人数趋势
项目完成趋势
项目提交趋势
社区活跃趋势
```

### 技术栈统计

例如：

```text
Python      35%
Java        30%
JavaScript  20%
C++         10%
其他         5%
```

可以使用 ECharts 等图表库进行可视化。

这部分不需要做成复杂的数据平台，但要能够体现：

> 数据采集 → 数据统计 → 数据分析 → 数据可视化

这对大数据专业毕业设计具有明显帮助。

# 13. 推荐技术栈

## 前端

推荐：

- Vue 3
- Vite
- TypeScript
- Element Plus
- Vue Router
- Pinia
- Axios
- ECharts
- Vue Flow / LogicFlow

其中：

**Vue Flow / LogicFlow** 可以重点用于实现可拖动、可连接、可编辑的工作流节点。

---

## 后端

推荐使用：

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- JWT

FastAPI 负责：

- 用户系统
- 项目系统
- 社区系统
- 工作台
- 工作流
- AI Agent 接口
- 数据统计接口

Python 与 AI 能力结合也比较自然。

---

## 数据库

主数据库推荐：

**MySQL**

用于保存：

- 用户
- 项目
- 课程
- 每日任务
- 工作流
- Prompt
- 社区帖子
- 评论
- 点赞
- 学习记录
- 数据统计

---

## Redis

Redis 可以作为辅助组件，用于：

- 登录状态
- Token / Session
- AI 请求缓存
- 热门项目缓存
- 热门数据缓存
- 简单排行榜
- 临时任务数据

毕业设计不需要强行让所有功能都使用 Redis。

---

## AI 接入

AI 不建议直接写死某一个模型。

建议设计统一 AI Provider：

```text
AI Agent
   │
   ├── OpenAI
   ├── DeepSeek
   ├── Claude
   └── 其他兼容 OpenAI API 的模型
```

后端通过统一接口调用。

这样以后更换模型只需要修改 Provider，而不需要修改整个业务系统。

---

## 文件与项目资源

如果需要保存：

- 项目截图
- 项目封面
- 用户头像
- 课程表
- 项目附件

可以使用：

- 本地文件存储（毕业设计开发阶段）
- MinIO（如果希望体现对象存储能力）

毕业设计阶段优先保证简单可靠。

# 17. 项目的核心创新点

### 创新点一：AI 辅助而非 AI 代做

平台不以“直接生成代码”为核心，而是帮助学生：

- 分析需求
- 拆解任务
- 制定学习路线
- 生成开发 Prompt
- 设计工作流
- 分析项目成果

强调学生自身的学习和实践过程。

### 创新点二：可编辑的 AI 开发工作流

通过可视化节点，将项目开发过程结构化。

节点之间具有上下文依赖关系，修改一个关键节点后，后续节点能够根据项目上下文进行调整。

### 创新点三：社区与个人工作台闭环

社区负责：

> 学习、发现、分享、交流

个人工作台负责：

> 计划、学习、开发、记录、总结

两者通过项目数据连接。

### 创新点四：学习数据分析

通过记录学生的学习行为、任务完成情况、项目开发情况等数据，实现：

> 数据采集 → 数据统计 → 数据可视化 → AI 分析

能够较好地体现大数据专业特色。

# 19. 最终项目定位

最终建议将项目定位为：

> **面向高校学生的 AI 辅助学习与代码实践平台**

项目不是简单的代码题库，也不是普通的校园论坛，更不是一个单纯的 AI 聊天网站。

它将：

**校园代码社区 + 个人学习工作台 + AI Agent + 可视化开发工作流 + 学习数据分析**

结合在一起。

最终形成一个完整的学生学习闭环：

> **学习 → 练习 → 项目 → AI 辅助开发 → 成果记录 → 数据分析 → 社区分享**

这套定位既能够控制毕业设计的开发规模，又能够体现前后端开发、数据库、AI Agent、可视化、数据分析等多个技术方向，适合作为大数据专业毕业设计进行实现和论文研究。
