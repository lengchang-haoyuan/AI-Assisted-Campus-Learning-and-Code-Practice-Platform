# P08 学习系统：可直接投喂给 AI 的提示词

基于 P07 的工作台，实现课程、学习计划、每日任务和学习记录的完整业务闭环。本阶段不接 AI，只保存可供后续报告使用的结构。

## 本阶段目标

实现 `Course`、`LearningPlan`、`DailyTask`、`LearningRecord` 的 CRUD 或项目规划中对应的完整读写接口。课程可被计划引用；计划具有日期范围和状态；任务可关联 plan/project，支持完成；记录保存学习时长、内容、日期和来源。`record_type` 至少支持 `study/project/workflow/ai/course/task`。

所有资源按当前用户隔离，服务端校验关联的 plan/project 是否属于当前用户。时长、日期、状态、标题和内容需要边界校验；列表支持分页或有界查询。计划、任务和记录的状态变化要定义清楚，避免完成任务与记录保存出现虚假成功。

## 执行要求与验收

先检查 P01 的表结构、P02 的分层、P05/P07 的 API 调用和类型，必要的 Schema/Model 兼容变更先说明。实现 Router → Service → Repository，增加关键成功和失败测试。验收：课程 → 学习计划 → 每日任务 → 完成任务 → 学习记录完整跑通；建议提交：`feat: implement learning system`。
