# P06 校园代码社区：可直接投喂给 AI 的提示词

在 P04/P05 的 Project 能力之上，完成校园代码社区的最小可用版本。社区围绕学习项目和成果分享，不扩展复杂社交系统。

## 本阶段目标

实现项目浏览、详情、标签筛选、发布、评论、点赞、收藏（仅当现有表结构已支持或经确认后实现）。评论接口至少包括：`GET/POST /api/v1/projects/{id}/comments`、`DELETE /api/v1/comments/{comment_id}`；点赞包括 `POST/DELETE /api/v1/projects/{id}/like`；浏览包括 `POST /api/v1/projects/{id}/view`。具体路径必须与现有 API 契约一致并同步前端。

复用 Project 作为社区和个人工作台的连接实体。服务端校验登录、资源存在、评论所有权和重复点赞/收藏；点赞、收藏应有唯一约束或等价幂等语义。列表支持标签筛选、分页、稳定排序和空状态。浏览量和互动数据必须从数据库读取，不能写死。

## 范围限制与验收

只做项目社区、评论、点赞、收藏、浏览；不做私信、好友、关注、实时聊天。前端完成社区列表、详情、筛选、互动和错误状态。验收：刷新页面后数据仍来自数据库，越权删除评论和重复互动得到正确结果。建议提交：`feat: implement campus code community`。
