# P05 Vue 前端基础框架：可直接投喂给 AI 的提示词

基于 P03/P04 已提供的认证和 Project API，实现 `ScholarHub` 前端基础框架和首条真实业务闭环。本阶段主要完成前端基础、认证页面和项目 CRUD。

## 本阶段目标

页面和路由：`/login`、`/register`、`/`、`/projects`、`/projects/:id`、`/workspace/dashboard`、`/profile`。实现 Router、auth/user store、project store、Axios request 封装、Token 注入、401 处理、登录后 Layout，以及 Loading、空数据、错误和重试状态。

页面必须通过真实 FastAPI API 工作，完成：注册 → 登录 → 项目列表 → 创建 → 详情 → 编辑 → 删除。前端使用明确 TypeScript 类型，不用 `any`、双重断言或全局关闭类型检查。API 请求集中在 `src/api`，组件不直接拼接 URL。

## 交互和安全要求

- 前端表单校验用于即时反馈，后端仍是最终校验边界。
- 防止重复提交，删除等危险操作需要确认。
- Token 不写入源码；存储方式与后端认证设计一致。
- 路由守卫只做导航体验，服务端仍校验权限。
- 页面具备加载、空、失败、成功状态；窄屏和长文本不破坏布局。
