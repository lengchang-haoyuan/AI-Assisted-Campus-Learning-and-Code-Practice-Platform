# P07 个人工作台：可直接投喂给 AI 的提示词

基于认证、Project CRUD 和社区能力，实现登录用户的个人工作台。本阶段先使用确定性业务逻辑，不依赖 AI。

## 本阶段目标

实现页面：`/workspace/dashboard`、`/workspace/tasks`、`/workspace/projects`、`/workspace/projects/:id`、`/workspace/records`。展示今日任务、最近项目、学习进度、项目进度和最近学习记录。Dashboard 必须由真实 API 聚合数据，不在前端写死统计。

任务支持创建、查看、完成和关联项目；学习记录保存学习时长、内容、记录类型和关联项目。所有数据按当前用户隔离，服务端校验任务和项目的所有权。请求层、Store、页面和组件职责清晰，处理加载、空、失败、重复提交和任务完成后的刷新/一致性。

## 本阶段禁止

不接 AI 计划生成、AI 报告、Workflow 执行或模型接口；不要为了展示效果伪造数据。先检查 P08 预定的数据模型是否需要兼容，但只实现本阶段要求的最小业务。

## 验收

登录后能够创建或查看任务，完成任务，关联项目，保存学习记录，并在 Dashboard 和记录页看到数据库中的结果。增加关键 API/Service 测试，建议提交：`feat: implement personal workspace`。
