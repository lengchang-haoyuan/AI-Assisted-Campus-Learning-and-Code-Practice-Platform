## 关键设计和调用链

- 后端保持 `Router → Service → Repository → SQLAlchemy Model → MySQL`；Router 不访问 ORM，Service 不拼 SQL，Response Schema 不直接暴露 Model。
- 复用 P01 已有 `workflows`、`workflow_nodes`、`workflow_edges` 表和 Models，未修改 `schema.sql`、数据库结构或迁移历史。
- Workflow CRUD、Node CRUD、Edge CRUD 和 `PUT /api/v1/workflows/{id}/graph` 均要求 JWT；Service 通过 Workflow 所属 Project 校验当前用户所有权。
- 整图保存使用稳定 `node_key` 引用、单事务替换和悲观锁版本复查；成功后递增版本，过期版本返回 409，避免覆盖其他编辑会话。
- 图校验限制最多 100 个节点和 300 条边，拒绝不存在节点、重复边、自环及有向循环；JSON、坐标、名称、类型和状态均有边界校验。
- 前端调用链为 `View/Component → Pinia Store → src/api → Axios → FastAPI`；画布组件只发出节点、边和选择事件，不调用 AI 或后端。
- 保存顺序为先原子保存图，再更新名称和状态，保证切换 `ready` 时后端已能看到持久化节点。
- 已有图在节点尺寸与响应式布局稳定后执行 `fitView`；空图不自动放大，新增节点保持稳定的 100% 初始缩放。
