## 2. 最小规则（实施前设计）

| 变更 | 规则 |
|---|---|
| 新的非空项目 | 所有本人所属、关联该计划的任务，其已保存 project_id 必须等于新项目；任务 project_id=null 也不能保留在非空项目计划下。无任务则允许。 |
| 清空计划项目 | 允许。计划不再要求统一项目，既有任务保留各自项目，不自动改写；沿用任务关联规则的现有语义。 |
| 新开始/结束日期 | 合并未提交字段与原字段后，先检查开始≤结束；每个任务日期必须落在新范围内，边界包含当天。 |
| 日期为 null | 对应侧无边界；清空两侧允许任务保留原日期。 |
| 同值、只改标题/说明 | 不因无变化的项目/日期重新校验已有任务，不借此修改存量数据。 |
| 相容缩小、扩大范围、无任务 | 允许，仍执行现有字段/所有权/状态规则。 |
| completed / cancelled 计划 | 使用相同项目/日期兼容规则；保留 L1 的任务集合、完成数量和进度，不新增全面冻结，不恢复为 active。 |
| 课程字段 | 保留现有所有权和可选字段语义；任务本身无独立 course_id。本步没有证据要求批量修改历史学习记录，不扩大课程整改。 |

新非空项目规则来自既有任务创建/关联逻辑：即使输入 project_id=null，服务也会继承计划项目。因此已有任务持久化字段必须实际相等，不能通过计划修改留下待以后编辑才继承的空项目任务。

## 3. 最小实现设计

1. Repository 增加两个仅查询的、按 plan_id + user_id 限定的方法：关联任务项目 ID 去重集合；关联任务日期 min/max。不分页，不加载任务正文，不按任务状态过滤。
2. Service 仅在项目实际变为非空时检查项目集合；仅在日期实际变化且仍有边界时检查新的完整范围。全部判断位于计划字段赋值之前，冲突沿用 `409 / conflict`。
3. 无任务得到空项目集合、空日期边界，合法更新继续保存。清空可选字段不自动改写任务或记录。
4. 学习计划页已有保存失败提示：捕获服务错误、显示 error.message、保留编辑器。先复用该路径，不改变 API 或新增前端策略。
5. 当前没有可复现的并发失配证据，不新增锁框架或数据库迁移；专用隔离 MySQL 刷新验收未获得可用确认连接，按用户本轮约定交 L4。

## 5. 关键决策与兼容性

- 用户本轮已明确授权“保存前检查已有任务并拒绝破坏约束的修改”，因此新增非法修改的 `409 / conflict` 属于已授权行为；合法请求结构和可选字段语义保持一致。
- 非空计划项目要求任务的**实际项目 ID 相等**，不把任务 project_id=null 当成稍后会自动继承；清空计划项目时保留任务自己的项目。该取舍来自现有 `_resolve_task_relations`，不是新增项目绑定偏好。
- 日期改变时检查提交后的完整范围，不能只检查新开始与新结束互相有序而忽略任务。等于任务日期允许，null 表示无边界。
- 全部任务状态均参加兼容校验，已完成/已取消的历史任务不能被忽略。终态计划允许相容项目/日期编辑，任务集合、完成数量、进度和计划状态保持原有规则。
- 同值和仅标题等编辑不触发新的任务检查，避免把修改无关字段变成存量数据清理。已存在的异常数据需另行决定处理方式，不由本步自动修正。
- 沿用 Vue 3 / TypeScript / FastAPI / SQLAlchemy / MySQL。API 路径、Schema、Models、数据库结构、依赖、构建和安全配置均未变；权限仍由服务端独立执行。

## 7. 前端与可执行手工验收

[计划编辑器](../../frontend/src/components/LearningPlanEditor.vue)已经将空项目/空日期编码为 null；[学习概览页](../../frontend/src/views/LearningOverviewView.vue)已有 `savePlan` 错误捕获，借助现有错误解析显示后端消息，失败时保留编辑器。因此本步没有新增前端校验或改变交互策略。

在已确认的专用演示/测试环境中：

1. 本人计划关联 A，已有任务继承 A；在“课程与学习计划 → 编辑”选择本人 B，同时修改标题后保存。应提示项目不一致，输入保留；刷新后计划仍为 A、原标题，任务仍为 A。
2. 将开始日期推到最早任务之后，或结束日期缩到最晚任务之前，分别保存。应出现开始/结束日期冲突，刷新后父子数据保持。
3. 将范围缩到恰好覆盖全部任务，或向外扩大，应允许；清空一侧日期表示该侧无边界。
4. 清空计划项目，应允许且任务项目保持；若需要换成 B，明确逐项调整任务自身项目，使其全部与 B 一致，再关联计划 B。涉及任务改挂入/出时仍受 L1 终态限制，不能通过该流程隐式重开计划。
5. 无任务时合法修改项目/日期、同值回传、只改标题应允许。分别对 completed / cancelled 计划核对相容编辑后状态、任务集合、完成数量和进度不变。
