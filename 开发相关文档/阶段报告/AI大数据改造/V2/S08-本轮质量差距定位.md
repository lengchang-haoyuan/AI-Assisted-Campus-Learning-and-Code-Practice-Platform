## 2 Q07：把已知零误分类，又重复归因到累加

冻结参考见 [S01 AI案例](S01-AI固定模板与评价案例.json)：`/cases/6/case_id=Q07`；`/cases/6/reference_criteria/C03=fail`、`/cases/6/reference_criteria/C04=pass`；唯一参考问题 `/cases/6/reference_issues/0` 为 `C03 / zero_as_missing`。本轮[被测输入](S08-评价运行/20261022-flash-pro-r1/inputs/Q07-under-test-input.json)的 `/code` 与该冻结代码一致，公开样例为 T01/T02。

相关代码原文为：

```python
if not duration:
    out["missing_duration_count"] += 1
else:
    out["known_duration_count"] += 1
    out["known_minutes"] += duration
```

已知整数 0 在 `if not duration` 中进入 missing 分支，混淆已知零与未知，影响已知/缺失行数。这是 C03，候选在 `/response/criteria/2` 正确标为 `zero_as_missing`，J1 对应项 `evidence_valid=true`。

额外误报发生在候选 `/response/criteria/3`：`verdict=fail`、`issue_type=sum_error`。其 `/reason` 明说“虽然加0不改变和”，随后仍以“该行未被当作已知分钟处理”判定 C04 失败。这里的依据仍是刚才的分类根因；现有累加运算本身是 `+= duration`，遗漏的是加数 0，并不改变分钟和。T01/T02 的已知分钟和均为 30，静态逐分支推导仍为 30；这不是运行学生代码所得的新成绩。

J1 `/response/criterion_evidence/3/evidence_valid=false`；同项 `/reason` 指出：“其主张的sum_error不成立，因为0分钟累加0不影响known_minutes，且该问题已由C03覆盖。”因此 `(Q07,C04)` 计一项 FP，并计一项 `unsupported_issue_cells`。C03 的 TP 不因这个额外错误被抹去。

候选 summary 还把 `known_minutes` 与两个计数字段并列为出错结果，定位为 `/response/summary`。它与 C04 理由中的“加0不改变和”形成候选自身的表述问题；不是源代码或冻结答案发生了变更。

## 3 Q10：空白被赋为零，仍不是独立的 sum_error

冻结参考同一文件的 `/cases/9/case_id=Q10`；`/cases/9/reference_criteria/C03=fail`、`/cases/9/reference_criteria/C04=pass`；唯一参考问题 `/cases/9/reference_issues/0` 为 `C03 / unknown_as_known`。本轮[被测输入](S08-评价运行/20261022-flash-pro-r1/inputs/Q10-under-test-input.json)的 `/code` 与冻结代码一致，指定公开样例为 T05。

关键原文为：

```python
duration = 0 if raw == "" else int(raw)
```

同一函数后续为：

```python
if duration is None:
    out["missing_duration_count"] += 1
else:
    out["known_duration_count"] += 1
    out["known_minutes"] += duration
```

空白分钟被提前转为 0，后续不会进入 None 分支，未知行被计为已知；该根因由 C03 覆盖。候选 `/response/criteria/2` 正确指出 `unknown_as_known`，J1 对应证据判 true。

候选 `/response/criteria/3` 又判 `fail / sum_error`，引用只有 `out["known_minutes"] += duration`；`/reason` 同时承认“该累加虽不改变总和数值”，却以 `known_duration_count` 增加和“已知分钟集合包含未知行”为 C04 失败理由。对于指定 T05 的两条空白分钟，错误实现会把已知行数加 2、缺失行数留 0，但两个错误加入的加数均为 0，分钟和仍为 0。分类与计数错误成立，独立的累加错误不成立；此处同样是静态推导，没有执行提交代码。

J1 `/response/criterion_evidence/3/evidence_valid=false`；`/reason` 明确指出：“其理由实际是C03分类错误导致的连带影响，而非累加逻辑本身错误。”因此 `(Q10,C04)` 同样贡献一项 FP 和一项 `unsupported_issue_cells`。
