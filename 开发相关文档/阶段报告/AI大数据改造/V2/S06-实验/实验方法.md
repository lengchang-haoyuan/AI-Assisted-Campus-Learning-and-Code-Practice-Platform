# S06 同口径规模实验方法

实验只使用合成离线文件。固定 `seed=20261020`，沿用 S03 `s03-synthetic-1.0` 生成器；1 万档是 S03 原输入的逐字节副本，10 万档是本轮新生成。两个档位均位于 WSL 同一 Linux 文件系统，避免以 Windows 挂载盘与 Linux 文件系统的差别替代算法差别。原 S03 快照和 S04 已完成任务不覆盖。

## 输入与环境

| 项目 | 1 万档 | 10 万档 |
| --- | ---: | ---: |
| 唯一学习记录 | 10,000 | 100,000 |
| 完全重复记录 | 200 | 2,000 |
| 合成主体 | 100 | 1,000 |
| 任务 | 2,500 | 25,000 |
| 提交群组 | 100 | 1,000 |
| 提交版本 | 130 | 1,300 |
| 教师反馈 | 110 | 1,100 |

窗口为上海时区 2026-10-01 至 2026-10-30；截点为 `2026-10-30T16:00:00Z`。分钟 20% 未知、10% 已知零；任务 50% 完成、25% 待办、15% 进行中、10% 取消；教学群组 30% 首次通过、30% 修订通过、20% 退回、20% 待评。每主体 100 条唯一记录，主体序号 mod3=0 的普通记录集中前五天，其余覆盖 30 天。

环境预检见 [preparation.json](preparation.json) 和 [Windows 硬件](windows-hardware.json)。使用已有 WSL 虚拟环境 Python 3.12.3、PySpark 4.2.0、Java 17.0.20.1；运行参数固定 `local[2]`、driver `2g`、shuffle `8`、Spark session UTC。未安装依赖、修改全局配置或连接数据库。

## 实现和计时边界

入口为仓库 `analytics/benchmark_s06.py`。Spark 复用 S04 `run_job`、显式 schema、质量检查、可信关联和 Spark SQL，包含 DWD/ADS Parquet 落盘。基线复用独立标准库 `fixture_answers.calculate`，读取相同 JSONL，逐主体执行相同关系、窗口、NULL/零、分母规则。参考实现每主体重复全表去重和关系检查，计入实际计算耗时；它不是最优 Python 或 SQL 基线。

先由独立 Python 生成全主体参考，核对生成器已保存的汇总答案；Spark 随后逐主体、逐字段和逐日核对。整数、比例六位小数及字段集合精确一致；只有未舍入反馈等待分钟允许 `1e-10` 浮点容差。两种实现共用输入及指标含义，Spark 不生成或修改独立预期。

每个档位、每个引擎各运行三次独立进程，标作“进程冷启动”；另一个进程预热一轮，随后测量三轮，Spark 在这个进程中复用同一个 JVM。预热不计入热轮中位数，原始结果照常保留。不主动清 OS 缓存，不能称“磁盘冷缓存”。本轮不添加或跨轮保留 DataFrame 缓存；S04 作业内已有三张事实层短期 persist，作业 finally 内 unpersist，方法保持不变。

每轮分别记录输入读取、计算、输出、答案验证及轮次全流程。冷进程额外记录外部进程墙钟时间与 Spark Session 启动时间。Spark 质量／事实时间含输入，汇总表扣除读取后再加 ADS 收集作为计算；剩余作业时间作为输出及最终对账，不能解释成仅磁盘写入。Python 的 JSON 输出和 Spark 的 Parquet＋JSON 输出不同，计算与完整作业两种时间均展示，不把产物格式差异藏在单一倍数中。

RSS 用 Linux `/proc` 每秒采样 Python 驱动及其子进程 JVM／Python workers 的 RSS 和，保留每轮与进程级峰值；这是采样峰值且共享页可能重复计数，不是精确内存峰值。三次进程冷与三次热轮各自报告中位数和全部原始值。

## 运行和边界

```bash
export PYSPARK_PYTHON=/home/administrator/scholarhub-analytics/.venv/bin/python
export PYSPARK_SUBMIT_ARGS='--driver-memory 2g pyspark-shell'
/home/administrator/scholarhub-analytics/.venv/bin/python -B -m analytics.benchmark_s06 prepare --output /home/administrator/scholarhub-analytics/s06-20261021
/home/administrator/scholarhub-analytics/.venv/bin/python -B -m analytics.benchmark_s06 run --scale 10000 --output /home/administrator/scholarhub-analytics/s06-20261021
/home/administrator/scholarhub-analytics/.venv/bin/python -B -m analytics.benchmark_s06 run --scale 100000 --output /home/administrator/scholarhub-analytics/s06-20261021
```

完成目录和已有日志拒绝覆盖，重试需保留失败并选新的实验输出目录。每个 `worker.json` 与 `*-process.json` 保留原始命令、退出码、轮次、资源和计时。正式结果以本目录后续产生的 `n10000-summary.json`、`n100000-summary.json` 和实验结果文档为准；仅准备完成不等于测量通过。

百万档、集群、真实教学成效及模型评价不在本轮实验范围。合成数据只能验证计算正确性和本机规模表现，不能证明平台真实用户数或教学因果关系；不预设 Spark 在这些数据量上更快。
