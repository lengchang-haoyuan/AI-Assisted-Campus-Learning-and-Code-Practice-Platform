- 日期：2026-09-06 +08:00
- 范围：原审核报告中可以局部修复的正确性、安全性及冗余问题。

## 需求摘要

以最小代码修改落实审核建议，优先保留项目整体功能、现有接口和工作区中的既有开发成果。原 Word 审核报告保留为修改前的审查快照，本报告记录本轮实际处理结果。

## 修改内容

| 原报告问题 | 本轮处理 | 保留边界 |
|---|---|---|
| H1 同步调用阻塞异步路由 | 89 个没有 await 的数据库或业务路由由 async def 改为 def，由 FastAPI 在线程池执行 | 真实 AI 异步调用与执行引擎继续保持原有实现；其中混合的同步数据库访问未整体迁移 |
| H2 工作台与学习模块规则漂移 | 阻止取消任务被完成；项目实践要求关联项目；工作台拒绝缺少课程或任务关联能力的记录类型，前端引导到已有学习系统入口 | 保留两套 API、服务和响应结构，不做跨模块合并 |
| H3 校园命名锁连接生命周期 | 显式持有连接并临时绑定现有 Session，提交或回滚后仍在原连接释放锁，再恢复绑定及归还连接；释放异常时作废连接 | 保留原锁名、等待时间、事务范围和管理员不变量 |
| H4 注册和验证码限流不完整 | 普通与邀请注册共用每客户端 8 次／300 秒额度；滑块获取和校验分别限制为 30 次／300 秒，检查先于业务处理 | 复用现有进程内限流器，不引入缓存服务 |
| M1 工作流状态所有权 | 手动更新只允许 draft／ready；运行期间拒绝手动切换状态；前端重命名仅发送 name，删除失效的状态事件与 savedStatus | 保留当前状态展示与直接运行流程，不新增状态选择界面 |
| M2 工具栏样式冲突 | 将当前实际使用的 flex 布局集中到 main.css，移除失效 grid 定位和 select 样式 | 保持现有折行行为与 700px 名称换行规则 |
| M3 教学字段残留 | 应用非教学节点配置时删除 problem 和 student_code | 保留其他扩展配置，避免整份白名单重建误删已有数据 |
| M4 保存提示失真 | 工具栏统一展示 dirty 或 configDirty，继续使用已有的未应用配置保存拦截 | 不改变应用配置、保存、运行的顺序 |
| 明确冗余 | 删除 4 个不可达前端文件、3 个未使用导入、1 个 return 后不可达表达式及失效样式和状态变量 | 其他仍可达的重复表单和实现保留 |

- 后端业务：`backend/app/services/workspace.py`、`backend/app/services/workflow.py` 增加局部校验；`backend/app/repositories/campus.py` 修正锁连接生命周期；`backend/app/agents/base.py` 清理未使用导入。
- 前端组件与页面：`LearningRecordForm.vue`、`WorkflowNodeConfigPanel.vue`、`WorkflowToolbar.vue`、`WorkflowEditorView.vue`。

- 未增加依赖、数据库迁移或运行服务；未调整构建、部署与检查配置。

## 关键设计决定

1. 处理实际错误分支，不合并工作台与学习服务。两条路径仍可工作，取消任务和缺少来源的记录不再被工作台绕过校验。
2. 不升级异步数据库技术栈。89 处路由签名修正覆盖纯同步业务，AI 混合调用链保留待后续单独评估。
3. 锁修复复用当前 Session，不创建第二套业务事务；同一连接覆盖获取锁、业务提交或回滚、释放锁完整过程。
4. 不清空整个节点配置，仅删除确认不再适用的教学字段，兼容其他自定义键。
5. 不恢复旧的状态下拉框。现有执行服务不要求用户先将草稿手动标记为 ready，保留当前直接运行体验。

## 兼容性与安全影响

- 修改前后 OpenAPI 完整 JSON 一致：68 个路径、102 个操作、170 个 schema，路径、请求字段及响应定义保持不变。
- 行为校验有意收紧：无效任务迁移、缺少来源的记录和客户端伪造执行状态返回现有 409 错误；超额认证操作返回现有 429 错误。
- 普通记录创建、项目关联、有效任务完成、工作流重命名与保存均保留。
- 同一出口 IP 共享认证额度，沿用项目现有客户端识别方式。现有限流器和滑块服务仍适用于当前单实例部署。
- 真实 MySQL 验证仅使用 SELECT 和会话级命名锁，不插入或修改业务数据。
- 当前工作区原有数据库与 P17 等改动属于既有开发内容，本轮未提交或推送 Git。
