## 2. 本阶段关键设计和调用链

提交链路为 Router → SubmissionService → SubmissionRepository → MySQL。学生只能在有效班级、有效学生成员、published 任务且服务端当前时间早于截止时间时提交。首次提交建立 Submission 和 V1；退回后才能追加 V2。`request_key` 与原请求快照共同处理网络重试，同键同内容返回原版本，同键不同内容或旧版本状态冲突返回 409。

教师只可在本人有效任教班级评阅最新 submitted 版本。退回或通过均固定到指定版本，写入 Feedback、版本状态、Submission revision 和学生通知；通过时同事务创建无时长 LearningRecord 系统事件，不修改 Project、DailyTask 或 Course。个人学习记录接口将系统事件视为只读，并以“未记录时长”展示，避免伪造学习分钟。

任务发布通知写入 P18 原发布事务；反馈通知写入 P19 评阅事务。通知按接收人分页、统计未读并幂等标记已读。教师专用响应只包含提交正文、仓库文字、版本标识、来源项目标题快照和反馈，不返回私人 Project ID、Context、笔记或 AI 输入。管理员没有提交正文权限。

数据表为 submissions、submission_versions、feedback、notifications；与 TeachingAssignment、ClassMembership 使用同班复合外键。教学历史使用 RESTRICT，私人 Project 来源和个人学习事件链接使用 SET NULL。数据库存 UTC，页面按本机明确时区格式化展示。
