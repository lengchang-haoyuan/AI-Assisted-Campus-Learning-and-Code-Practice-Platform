主调用链保持：

```text
Vue View / Component
  → src/api + Pinia
  → FastAPI Router
  → Service（授权、状态、事务）
  → Repository
  → SQLAlchemy Model
  → MySQL
```

AI 链路保持：

```text
Project Context / Agent / Workflow / Learning Report
  → AIClient
  → DeepSeekProvider 或测试 FakeProvider
  → Pydantic 结构校验
  → AIRequest / AIResult / WorkflowRun 持久化
```

## 3. 启动命令及必要环境变量

环境要求：Node.js 22+、pnpm 11+、Python 3.11+、MySQL 8.0+。

后端：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

前端：

```powershell
cd frontend
pnpm install
Copy-Item .env.example .env
pnpm dev
```

后端 `.env` 至少需要 `DATABASE_URL` 和长度不小于 32 的 `JWT_SECRET`。真实 AI 需要另行配置 `DEEPSEEK_API_KEY`；Key、数据库密码、JWT Secret、邀请和重置凭证均不进入 Git。
