## 2. 关键设计和调用链

继续使用 `Vue → Axios → Router → Service → Repository → SQLAlchemy → MySQL`。Agent 调用经过 AIClient/Provider，结构化结果校验后由服务层持久化。本次没有新增 Provider、业务路由或执行工具。

进度以项目所有者的全部关联任务完成率为准，先按工作台已有 Python `round` 语义取整数，再计算平台或当前用户平均值。SQL 使用整数余数保留 `.5` 偶数取整（如 1/8 为 12，3/8 为 38），避免 MySQL `ROUND` 与工作台不同。没有任务时回退原字段；不回写项目进度，不改变完成状态，也不改写历史报告快照。

报告等待覆盖后端 AI 总超时硬上限 180 秒并预留 10 秒响应余量，没有全局延长普通 API。退出/过期会话完整导航只发生在认证边界；公开登录页错误密码仍保留表单并显示 401，不重载页面。授权继续由服务端完成。

临时测试数据来源明确，使用随机账号与密码，不打印凭据。默认全链路仅替换外部 Provider；前端专项只模拟延迟/失败报告 HTTP 响应，假报告不落库，不能当作真实模型结果。真实 Provider 验收独立执行并成功。
